# 扉頁

## 關於本標準

應用程式安全驗證標準（Application Security Verification Standard，ASVS）收錄了一組應用程式安全要求，可供架構師、開發人員、測試人員、安全專業人員、工具廠商和使用方用於定義、建置、測試和驗證安全的應用。
